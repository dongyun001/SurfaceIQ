## 1. 目标与非目标

### 要什么

1. 在**圆形零件**上，自动找出位于外缘与中心孔之间的**成组暗孔**，逐个给出直径（px，有系数时给 mm）。
2. **自适应优先**：不需要型号档案、不需要事先告诉孔数、角度、孔径。
3. **通用性来自分层**：检测与排列解耦，排列校验是策略函数，新增形态加策略而不是加分支。
4. 输出**证据**（点数、票数、圆度、轴比、对比度），让低置信度的孔显式可见。

### 不要什么

- 不做型号识别、不做档案、不命名、不判 OK/NG。
- 不做方形零件的参考系（当前没有方形件；将来需要时另立策略，见 §8）。
- 不新增第三方依赖（仍然只有 `opencv-python` + `numpy`）。
- 不在本轮改 GUI（先让 CLI 在真实图上跑通，见 §5.4）。

正常件在阈值 **0.62** 下会掉一个孔（188°），在 0.55/0.70/0.74 下是 6 个。
**单一阈值会漏检**，所以检测必须跨多个阈值收集候选再合并。

### 2.5 边界是一条软坡（决定了取边定义）

孔的径向剖面：暗平台约 41~50 灰阶，亮平台 255，过渡带从半径约 35px 延伸到 70px。
同一张图上，不同定义给出的直径：

| 定义 | 直径 |
|---|---|
| 局部归一化阈值 0.55 | 4.26mm |
| 局部归一化阈值 0.72（旧代码 `rim_cross_points`） | 4.55mm |
| 原始灰度 50% 平台中点 | 4.64mm |
| **梯度最大（steepest）** | **4.73mm** |

（以上按重标后的 0.043579 mm/px；px 读数不变。）

**最终采用「梯度最大」，不是 50% 中点。** 50% 中点会被**暗平台的绝对亮度**带偏：

## 4. 算法设计

### 4.1 检测层：与排列无关

输入：BGR 图；以及已算好的外圈椭圆 `(c, R)` 与 `edges` 清单。

1. `gray` → `sm = GaussianBlur(σ=5)`（与现有管线同一张平滑图）。
2. `norm = sm / max(blur(sm, W×W), 1)`，`W = odd(round(0.2·R))`，下限 31px。
   （旧代码硬写 201，对应 R≈1013；这里改成随 R 缩放，便于跨零件。）
3. 环带掩膜：
   - 外边界：外圈椭圆 ×0.98；
   - 内边界：取 `edges` 里**最内侧那条非外缘边**（`e["src"] != "outer"`）的半径 ×1.05
     （不命名，只作几何内界）。本件是 0.624R ×1.05 = 0.655R，孔的内侧约 0.703R，留 39px 余量。
   - **只有外缘一条边时**（实心盘）不能用它自己当内界，直接退到 `0.55R`。
4. **多阈值收集**（不是逐档 break，而是全跑再合并）：
   `THRS = (0.55, 0.60, 0.62, 0.65, 0.70)`（这五个值都在 2026-11-02 的图上实测过）
   每个阈值：`dark = (norm < thr) ∧ 环带` → `findContours(RETR_LIST, CHAIN_APPROX_NONE)`。

   > **阈值只用于「定位候选」，不参与最终直径。** 最终直径由 §4.3 用 50% 平台中点重新量，
   > 所以换一个检出门槛不会让读数漂移——这是把「检测」和「定义」拆开的关键。
   > 实测也印证：门槛从 0.55 提到 0.70，暗斑外接直径从 96~108px 变到 104~117px，
   > 但 50% 中点量出来仍是 4.5~4.8mm。
   - **必须 `RETR_LIST`**：`RETR_EXTERNAL` 会把环面暗槽里的孔当成「洞」整个丢掉（旧代码 2026-10-22 实测踩过）。
5. 单候选筛选（全部按 R 归一化，避免绑死机位）：
   - 面积 ∈ `[0.002·R², 0.05·R²]`；
   - 圆度 `4πA/P² ≥ 0.70`；
   - 外接框长边 ≤ `0.35·R`（挡整圈暗槽）；
   - 到圆心距离 `d/R ∈ [内界, 0.95]`。
6. **跨阈值合并**：中心距离 < `0.02R` 的候选视为同一个，保留点数/票数最高的一版，
   记录 `votes = 命中它的阈值个数`（1~5）。
7. 输出候选：`[(cx, cy, r_blob, votes, circularity, area, thr_best), …]`。

> 设计取舍：阈值仍是启发式。之所以采用固定阶梯，是因为 `norm` 已经是局部归一化量，
> 暗孔通常在 0.2~0.4、亮面在 1.0~1.2，阶梯有物理意义。**但这些数值只在两类零件上验证过，
> 引入第三种件必须复核**（写进 §6 验收）。

### 4.2 排列校验：可插拔策略

候选本身**不假设任何排列**。校验层负责把「一堆暗斑」变成「一组可信的孔」：

```
validate_equidistant_circle(cands, c)   等角共圆（现有 6 孔件）
validate_rectangle(cands)               矩形四孔（4 孔件）
validate_generic(cands)                 不校验排列，只要求 ≥2 个且直径接近
```

**`validate_equidistant_circle`**

- 取候选数 `n`（≥3）；
- 角度按圆心排序，相邻角差应 ≈ `360/n`，容差 **±5°**（实测 58.9~60.8°，±1.2°）；
- `d/R` 极差 < **5%**；
- **不用暗斑外接尺寸做判据**：那个尺寸随阈值在 96~117px 之间漂，拿它卡直径会把 6 个真孔
  判成"直径不一致"、退到 3 孔的子集（2026-11-02 实测）。最终直径由梯度最大重算，排列只看位置。
- 所有槽位命中才返回 `("equidistant_circle", n, 残差)`，否则返回失败原因。

**`validate_rectangle`**

- 恰好 4 个候选；
- 旋转无关判据：**对角线互相平分**（`|p1+p3 − p2−p4| / 平均边长 < 3%`）
  且 **两条对角线等长**（相对差 < 3%）；
- 同样**不用暗斑外接尺寸**做判据（理由见上）。

**`validate_generic`**

- **≥3 个候选**。门槛是 3 而不是 2：实心盘上实测会冒出 1~2 个孤立暗斑，2 个候选凑不出任何
  排列，报成"2 个孔"就是假阳性。2 孔零件会落到"未成组"，需要时再单独立规则。
- 不校验排列，**必须带 `unchecked=True`**，报告里写明「未做排列校验」。不许伪装成可靠读数。

**调度（自适应优先）**

1. 先试 `equidistant_circle`；
2. 再试 `rectangle`；
3. 都不成立就 `generic`，并在报告里列出失败原因（角差超差 / 半径散 / 直径散）。

> 这条正是 AGENTS §0 的教训：**新增形态加一个策略函数，不要加一个枚举值**。

### 4.3 单孔边界与直径

对每个通过校验的孔中心 `(hx, hy)`：

1. **搜索半径**：`max_r = min(2.6·r_blob, 0.7·dist_nearest_edge)`。
   本件孔的 `r_blob≈50px`，到中心孔边缘约 125px、到外缘约 256px，所以 `max_r≈87px`。
   **这一条是防串扰的**：不留余量就会把中心孔边缘当成本孔的亮平台边界，读数会悄悄偏大。
2. 每条射线求**暗平台**与**亮平台**（都相对 `r_blob`，且在 `max_r` 以内）：
   - 暗平台：`0.50·r_blob ~ 0.85·r_blob`（本件约 25~42px，灰度约 41~50）；
   - 亮平台：`1.30·r_blob ~ 1.70·r_blob`（本件约 65~85px，灰度约 250~255）；
   - 若亮/暗平台差异 < 15 灰阶 → 该射线丢弃（对比度不足）；
   - 若亮平台取样段不足 5px（被 `max_r` 截断）→ 向内侧放宽到 `1.15·r_blob`。
   - **两个平台只用来判断这条射线可不可用，不参与定位。**
3. 在 `[0.5·r_blob, max_r]` 内取**正向梯度最大**点（与 `find_edge_points(mode="steepest")`
   同一套定义），抛物线插值到亚像素。不用 50% 中点（会被暗平台亮度带偏，见 §2.5）。
4. 点集 → `filter_and_fit(pts, hx, hy, r_blob)`（复用现有鲁棒拟合，不写第二份）。
5. 记录：`dia_px=(a1+a2)/2`、`a1`、`a2`、`ang`、`n_points`、轴比、对比度。
6. `n_points < 36`（0.5×72）判为**边界失败**，该孔标 `status="失败"`，
   **仍然列出位置**，不静默消失。
   `36 ≤ n_points < 43`（<0.6×72）标「低置信度」。

### 4.4 证据与置信度（不替用户判真假）

每个孔都带：`n_points / votes / circularity / aspect / contrast`。
每组都带：`arrangement / 角度残差 / 半径散 / 直径散`。

报告措辞的底线：

- 不写「这个孔是 M4 通孔」；
- 只写「H3 直径 4.71mm（108px），62/72 点，5/5 票，轴比 1.02」；
- 低置信度必须显式告警，不能与正常孔混在一起。

## 8. 已知风险与失败条件

| 风险 | 表现 | 处理 |
|---|---|---|
| 阈值阶梯不跨件通用 | 新零件孔全漏或全是噪点 | 必须做 §6.5 复核；报告里写明阈值 |
| 高光洗白 | 点数少、轴比大（本件已有 2/6） | 标「低置信度」，不静默丢弃 |
| 孔内装亮色紧固件 | 暗区变成环，50% 中点量到的是沉孔口/暗芯 | 当前不识别；报告如实给边界，人不满意再另立策略 |
| 孔与暗槽粘连 | 轮廓面积超上限被排除 | 报告「有候选因面积/粘连被排除」 |
| 单孔或两孔件 | 排列校验必失败 | 落到 `generic`，明确写「未做排列校验」 |
| 非等分成组孔 | 等角校验失败 | 落 `generic`；将来可加「同半径+同直径」弱校验策略 |

### 12.2 实现中由数据推翻/确定的三件事

1. **边界不用 50% 平台中点，改用梯度最大。** 50% 中点会被暗平台的绝对亮度带偏：
   同一个孔暗平台 37 时量 116.3px、70 时量 102.2px（差 13.7%）；梯度最大给出 108.5 / 104.0px
   （差 4.3%）。且与同心边的 `steepest` 同一定义。
2. **排列校验不看暗斑外接尺寸。** 那个尺寸随阈值在 96~117px 漂，拿它卡直径会把 6 个真孔
   判成"不一致"、退到 3 孔（120°）的子集（首版实测）。
3. **generic 门槛从 ≥2 提高到 ≥3。** 实心盘实测冒出 2 个孤立暗斑，≥2 会报成"2 个孔"。

另外：孔的搜索半径必须**逐射线**按到最近同心边的距离限制（`_ray_edge_limit`）。
首版用全局最小值，孔紧挨 #4 边（只差 60px）时把所有射线都砍掉，6 个孔全部"边界失败"。

4. **单档候选的 `votes` 字段缺失（2026-11-02 夜间实测暴露）**：`find_dark_blobs` 的合并分支
   会给 `votes` 赋值，但「只被一档命中、从未合并过」的候选走 else 分支时没有这个字段，
   统一赋值处抛 `KeyError`。白天每帧的候选都至少被两档命中，所以一直没触发；
   削顶 13.3% 的夜间帧产生了单档候选才暴露。已修（else 分支补 `votes=1`），回归门 px 不变。

### 12.6 亮环路径（2026-11-03）

装好紧固件的孔，暗斑法会把**暗芯 + 周围暗影**连成一个大斑：4 孔件只找到 3 个假候选。
改为找**亮环**（阈值 1.05~1.20，亮区外轮廓，圆度 ≥0.72，d/R 0.55~0.95），再套矩形校验。

实测 4 孔件：

| 项 | 结果 |
|---|---|
| 检出 | 阈值 1.05/1.10/1.15/1.20 下都是**恰好 4 个** |
| 角度 | 67.0 / 140.7 / 246.8 / 317.6°（矩形布局） |
| 直径 | 85.4~87.9px = **3.72~3.83mm**，极差 2.9% |
| 边界含义 | **螺钉头/沉孔口**，不是通孔内壁 → 报告必须标「亮环」 |

逻辑顺序（重要）：暗斑等角/矩形失败 → **亮环矩形** → 暗斑 `generic`（≥3）。
**`generic` 必须最后**，否则 3 个假暗斑会先把孔收下，亮环路径永远不执行（首版实测）。

**决策（2026-11-03，用户确认）**：4 孔件量**亮环**（约 3.80mm），不是暗环/通孔。
亮环 = 螺钉头/沉孔口的外轮廓；报告已标「亮环」，GUI 也显示「4 孔 · 亮环边界」。
