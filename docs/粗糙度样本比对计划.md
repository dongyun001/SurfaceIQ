## 1. 先说清物理限制（决定这件事能做到什么程度）

当前配置（25mm 定焦，WD≈615mm）：

```
mm/px ≈ 0.0436      一个像素 = 43.6µm
物体模糊 ≈ 127µm    （f/4，2.44·λ·N/m）
```

而 Ra 1.6µm 的表面，特征波长通常在 **10~30µm** —— **低于一个像素，也低于模糊直径**。

**结论**：现在这套光学看到的**不是粗糙度形貌本身**，而是"加工工艺留下的视觉指纹"：

- 刀纹（feed marks）的方向、间距、连续性；
- 加工纹理的粗细与均匀性；
- 镜面反射 vs 漫反射的比例（高光团形态）。

所以输出**不是 Ra 值**，只能是：**"最像哪个参考样本 + 距离是多少 + 是否超出已知范围"**。
这与 AGENTS §1 定义的业务线②一致，但必须写进报告，避免被当成粗糙度计。

**要看真形貌的话**（阶段 2 的备选）：2× 双远心（物方 Ø5.5mm、0.925µm/px、
f/8 下模糊 ≈5.4µm）+ 斜射/暗场光。那时能分辨 5~10µm 尺度的纹理。

## 2. 可行性门槛（先测，再谈实现）

要量三层散布：

| 层 | 怎么做 | 代表什么 |
|---|---|---|
| **within-位置** | 同一块，3~5 个不同位置各 1 帧 | 刀纹不均匀 |
| **within-帧** | 同一位置，连拍 3 帧 | 噪声/曝光抖动 |
| **between-样本** | 不同粗糙度样本之间 | **真正的判别信号** |

**判据**：

```
比值 = between 距离 / max(within-位置, within-帧)
≥5   → 有戏，进入阶段 1
3~5  → 勉强，需要更强特征或更稳的照明
<3   → 换光学（2× 远心 + 斜射光）或换特征
```

这个比值必须在**同一批数据**上算出来，不许凭经验拍阈值。

## 3. 采集协议（不锁死这四条，特征全是光照的函数）

1. **机位固定**：相机高度、倾角、镜头、对焦全部不动。换任何一项，参考库作废。
2. **固定曝光**。不要用 `auto_exposure`——它会随样本反照率自动调整，把"样本更暗"误读成"纹理不同"。
   做法：固定曝光值，或者每块先拍一块标准白/灰卡做亮度归一化。
3. **光源固定**：类型、角度、强度。纹理特征对**光的角度**比对强度更敏感（斜射光能打出刀纹，正光打不出）。
   现在的灯是什么类型需要确认（环光 / 条形 / 穹顶），它决定了能看见哪种纹理。
4. **ROI 固定**：固定像素尺寸（建议 **400~500px 见方**），避开边缘、倒角、划痕、油污。
   30mm 见方的样块在当前倍率下约 690px，400~500px 的 ROI 放得下且留有余量。

**每个样本**：3~5 个位置 × 3 帧，记录位置编号。

**必须记录的元数据**：样本号、加工工艺、标称 Ra（或"粗/中/细"分级）、曝光、光源、ROI 坐标、日期。

## 4. 特征候选（全部 numpy/opencv，不接分类器）

先试 4 个，够不够看门槛比值，不够再加：

| 特征 | 怎么算 | 为什么 |
|---|---|---|
| 多尺度局部标准差 | 窗口 5/15/45px 的 std，取比值 | 纹理粗细的直接代理，对尺度敏感、对亮度不敏感 |
| 带通能量 | 拉普拉斯或 DoG 的方差，多尺度取比 | 比单一尺度稳，能区分"细密"和"粗疏" |
| 梯度幅值分位数 | p50 / p90 / p99 | 对少量深刀纹敏感（分位数不吃离群值） |
| **刀纹方向与间距** | ROI 的 FFT 功率谱，取径向峰位与角度各向异性 | 车削/铣削纹理最有判别力的特征，且与亮度无关 |

可选：高光/饱和像素占比（对 Ra 敏感，但**极依赖照明角度**，只作为辅助）。

**归一化**：所有特征先除以同一 ROI 的均值亮度或标准差，再进距离计算。
不归一化的话，距离会被"这块更亮"主导。

**明确不做**：GLCM + 分类器那一套。GLCM 本身可以当描述子，但一旦接上 SVM 就是被删掉的技术栈。

## 5. 存储与判定

- **参考库**：每个样本一条记录——特征向量 + 采集条件 + 标签（工艺/标称）。
  格式用 JSON（和 `rig.json` 一样，人可读、可 diff），**不要二进制**。
- **距离**：特征标准化后的欧氏距离；同时给出最近邻与次近邻（两者差太小说明分不开）。
- **阈值 T**：由 §2 实测的 within/between 分布定，**不许拍脑袋**。
- **输出三档**：`同类（距离 < T_same）` / `未知（> T_diff）` / `中间（需人工）`。
- **必须打印采集条件**：换了灯或曝光，参考库就不该被信任，要显式告警。

### 6.5 样本集与预期难度（用户 2026-11-03 提供：8 种工艺）

| 工艺 | 纹理形态 | 典型间距 | 0.3×（模糊 36µm） | 备注 |
|---|---|---|---|---|
| 刨 | 直线往复刀痕 | 0.1~1mm | ✅ 富余 | 最粗、最容易区分 |
| 平铣 | 圆弧铣削纹 | 0.1~1mm | ✅ | 圆弧半径与刀径相关 |
| 端铣 | 端面圆弧纹 | 0.05~0.5mm | ✅ | 与平铣是"近亲" |
| 车 | 环形进给纹 | 0.05~0.5mm | ✅ | 方向固定（同心弧） |
| 镗 | 环形进给纹 | 0.05~0.3mm | ✅ | 与车是"近亲" |
| 外磨 | 细磨痕（常交叉） | 0.01~0.05mm | ⚠️ 吃力 | 需 2×；且是圆柱面 |
| 平磨 | 细直磨痕 | 0.01~0.05mm | ⚠️ 吃力 | 需 2× |
| 研磨 | 无方向细痕 | 0.005~0.02mm | ❌ | 需 2×，且可能仍难 |

**预期可分离性（先接受这个现实，再谈实现）**：

- **粗纹 5 种 vs 精纹 3 种**：两组分开很容易（尺度差一个数量级）；
- **组内近亲**：车 ↔ 镗（同为环形进给纹）、平铣 ↔ 端铣（同为圆弧纹）、
  外磨 ↔ 平磨（同为细直磨痕）——这三对**在任何倍率下都难分**，
  差别在纹理间距与方向分布，不在"看得清不清"；
- 所以"8 种全部区分开"不是必然结果。**先接受"能分出几组"**，再决定组内区分值不值得升级。

**三个采集上的额外要求**：

1. **刀纹方向必须固定**（每块按同一朝向摆），否则方向类特征会把"换了朝向"当成"换了工艺"。
   若无法固定，就用旋转不变的描述子（多尺度 std、带能量、FFT 各向异性幅度），
   但会丢掉"直线 vs 圆弧"的判别力。
2. **外磨是圆柱面**：ROI 要小（1~2mm），并且扣掉沿弧面的低阶亮度梯度，否则特征里混进照明梯度。
3. **研磨是无方向的**：这类样本不要用"方向/峰位"特征，用各向同性的尺度特征。

## 10. 实测记录（2026-11-04，0.3× 首测）

> 目的：先量「同一块内部抖动」与「不同 Ra 之间距离」。**合格阈值待定**（用户 2026-11-04：
> 以后再定，先按不同 Ra 记录）。
> 这批数据拍于**同一机位**（镜头/光照/机位未动）；用户随后要调机位，
> **调完新拍的数据属于新机位，不能与这批混比**。

**装置**：0.3× 顶视（按镜头标称 6.17µm/px），环光正面打，海康 4024×3036。
**自动曝光未锁**（6 帧分别 33115 / 44153 / 36889µs 和 39636×3µs，最大差 33%）。
样块小方形、平放；两块刀纹在画面里都接近水平（90°）。
文件：`data/captures/capture_single_20261104_12*.jpg`（不入库）。

### 10.1 车 Ra 6.3

- 主刀纹间距：512×512 窗口 + 零填充 FFT 取「最低频强峰」→ 三帧中位
  **53.9 / 53.8 / 53.8px = 332µm**，帧间极差 **0.04px（0.1%）**。
- 单个 ROI 有 **6~8%** 偏离中位 >20%（峰跳到谐波/次峰），但中位数的 MAD 只有 0.04~0.07px
  → **必须多位置取中位，不能看单个 ROI**。
- 方向 90°；强二次谐波（约 166µm）→ 刀纹是锯齿形，不是正弦。
- 饱和像素 1.0~2.5%（右侧高光团）；ROI 均值亮度 28~105（左右梯度很大）。

### 10.2 车 Ra 3.2

- 主刀纹间距：三帧中位 **24.4px = 150µm**（三帧完全相同），MAD 0.01px，**0%** ROI 偏离 >20%。
- 方向 90°；饱和像素约 1%（2% 饱和阈值下剔除 27/108 个候选 ROI）。
- 与 6.3 的间距比：332 / 150 = **2.2 倍**（进给约减半，与 Ra 从 6.3 降到 3.2 相符）。

### 10.3 特征实测（修正后）

**先记一个实现错误（会静默算错，必须写下来）**：
「多尺度局部标准差」最初写成 `sqrt(mean(m2) - mean(m)**2)`，其中 `m2 = blur(n²)`、`m = blur(n)`。
这个式子在数学上等于**整幅全局方差**，对窗口大小几乎不敏感——实测 5/15/45/135px 四个窗口
给出 10.7 / 10.68 / 10.68 / 10.68%，看起来「没有判别力」，其实是算错了。
正确写法是 **`sqrt(mean(m2 - m*m))`**（先逐点算局部方差再平均）。合成条纹自检
（周期 54px、幅度 10、噪声 2）：旧式四个窗口恒为 7.36，新式 2.28 / 3.89 / 7.10 / 7.30。

修正后，逐 ROI 的单特征比值（块间差 / 块内 std）：

| 特征 | T6.3 | T3.2 | 比值 |
|---|---|---|---|
| `log(S15/S135)` | -0.66±0.06 | -0.31±0.04 | **7.2** |
| `log(S5/S45)` | -1.55±0.18 | -1.00±0.03 | **4.2** |
| `log(period)` | 3.99±0.01 | 3.27±0.26 | **3.8** |
| `log(p50 梯度)` | 0.00±0.51 | 0.31±0.62 | 0.6 |
| `log(p99/p50)` | 1.67±0.48 | 1.57±0.24 | 0.3 |

**窗口必须与刀纹周期匹配**：这块样品的周期是 24~54px，5px 窗口基本只看到噪声；
尺度和带宽特征要用 **15~135px** 这一档，不能照搬计划里「5/15/45」的默认值。

### 10.4 门槛结论（按「实际读数」算）

实际工具不会看单个 ROI，而是**多位置取中位**。按每帧中位读数：

| 读数 | T6.3（三帧） | T3.2（三帧） | 块间差 | 帧噪声 std | 块间/帧噪声 |
|---|---|---|---|---|---|
| `log(S5/S45)` | -1.681 / -1.585 / -1.664 | -0.992 / -0.991 / -0.993 | 0.651 | 0.036 | **18** |
| `log(S15/S135)` | -0.702 / -0.675 / -0.697 | -0.304 / -0.304 / -0.304 | 0.387 | 0.010 | **38** |
| `log(period)` | 3.987 ×3 | 3.194 ×3 | 0.793 | 0.0001 | **~7000** |

**结论**：

1. **这两块（车 6.3 vs 车 3.2）在 0.3× 下分得非常开**：尺度特征 18~38 倍、周期约 7000 倍，
   远超 §2 的「≥5 有戏」。
2. **但必须多位置聚合**：如果只取单个 512×512 ROI，同一块内部的位置差异（表面本身不均匀）
   会把比值压到 3~7，甚至更低。工具必须按协议取 3~5 个位置的中位。
3. **逐 ROI 的 5 维欧氏距离不能直接用**：把无判别力的梯度/能量特征等权混进去，
   比值会掉到 0.96~0.99（之前误判「分不开」就是这个原因）。距离度量必须以「尺度 + 周期」
   这类稳定特征为主。
4. 梯度分位/带通能量在**这两块之间**没有判别力（比值 0.3~0.6），暂时只作辅助。

### 10.5 注意与下一步

- **间距/尺度是「进给与纹理粗细」的代理，不是 Ra**：同一进给、不同 Ra（刀具磨损、振动）
  可能分不开。阈值定下来后，必须补「同进给、不同 Ra」的样块验证，否则只能保证
  「能分不同进给」，不能保证「能判 Ra 合格」。
- 这次只有**一对**（6.3 vs 3.2、同工艺、同朝向），不能外推成「8 种都能分」。
- 自动曝光未锁：本次中位读数对曝光不敏感（帧间 0.1%），但正式采集仍应固定曝光；
  高光团还造成 1~2.5% 削顶，建议把环光调低/避开直反。
- 机位即将调整：**这批只代表当前机位**；调完以后按新机位重拍，参考库也要重建。
- 待办：定阈值 → 选「跨阈值」的两三块 → 在新机位、固定曝光下重拍 → 用本节同一套算法
  重算每帧中位的 between/within，再定 T_same / T_diff。
