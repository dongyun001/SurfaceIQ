# SurfaceIQ（锐感视觉）

基于机器视觉的**金属圆环/法兰零件尺寸测量系统**。

工业相机拍摄零件 → 亚像素射线边缘检测 + 椭圆鲁棒拟合 → **列出检出的每一条同心边**
（直径 px 与毫米数，编号标在图上）。**不命名、不判 OK/NG**：哪条边是外径/中心孔/内孔，
由人对着标注图和图纸判断。换算系数是**机位级的一份**（`models/rig.json`），不需要给零件建档。

> ⚠️ **2026-10-23 起改为"通用量测"模式**：型号档案、型号自动识别、螺栓孔测量、OK/NG 判定
> 都已删除。下面「检测管线」「已知限制」「实测数据」里仍有一些**旧模式的描述**
> （中心孔/螺栓孔/档案/标定流程），**以本文档开头和 `AGENTS.md` 为准**，
> 详细改造记录见 `docs/通用量测模式计划.md`。

## 快速开始

双击 **`vision-roughness\测量.bat`**：

| 操作 | 效果 |
|---|---|
| 直接双击 | 打开窗口：先亮约 1.2 秒实时画面，再自动测一次并出数字 |
| 把照片拖到 `测量.bat` 图标上 | 改测该照片，不拍新图 |
| 顶部「型号」下拉框 | 默认「无档案试测（只给像素）」；手动选档案里的型号才会给毫米数。选完自动重测一次 |
| 窗口内 `空格` / `F5` | 再测一次 |
| 窗口内 `P` | 暂停 / 继续实时画面 |
| 窗口内 `Esc` | 关闭 |
| 「看大图」/「打开报告」 | 用系统看图器 / 记事本打开产物 |

窗口左列用大字给出**最外那条边**，下面按半径由外向内列出检出的每一条同心边（带编号与毫米数）；
右列是**实时取景画面**（12MP 实测约 7.7 fps），测完自动冻结在**标注图**上
（绿=外缘 / 红=亮→暗边 / 品红=暗→亮边，编号与数值标在图上）。
**本模式不命名**：哪条边是外径/中心孔/内孔，由你对着标注图和图纸判断；也不判 OK/NG。
现场光弱时可勾选「预览增亮 ×3（仅显示，不影响测量）」看清零件位置——它只改显示亮度，不参与测量。
出错时把 `0x80000203` 这类错误码翻译成中文提示，不会出现「双击了没反应」。

> **型号识别已删除（2026-10-23）**：以前不传 `--profile` 会用极坐标指纹自动认型号，
> 现在**不猜**——没选型号就只给像素、标「未经验证」，毫米数要选了型号才有。
> 原因见 `docs/设计决策记录.md` §5（已废止）与 `docs/已知缺陷.md` 缺陷 2/5。

每次测量自动在 `vision-roughness\debug\` 存两份记录：

| 文件 | 内容 |
|---|---|
| `measure_ring_debug.jpg` | 画出检测轮廓的图（绿=外圈，红=中心孔，蓝=各螺栓孔） |
| `报告_年月日_时分秒.txt` | 文字报告（时间 / 图像 / 换算系数 / 全部尺寸 / 判定，UTF-8） |

## 首次搭建

```bash
cd vision-roughness

# 1. 建虚拟环境（用 Python 3.11，现有 venv 是 3.11.9）
#    必须用 venv 的 python —— 系统 Python 缺 cv2
py -3.11 -m venv venv

# 2. 装依赖（只有两个包，很快）
venv\Scripts\python.exe -m pip install -r requirements.txt

# 3. 验证
venv\Scripts\python.exe -c "import cv2, numpy; print(cv2.__version__, numpy.__version__)"
```

**接海康相机还需要**：

1. 装海康机器人 **MVS** 软件（安装时勾选 Python SDK 组件）；
2. 用 MVS 客户端确认能枚举到相机、能出图（确认完**关掉 MVS**，它会占用相机）；
3. 核对 `src/config.py` 的 `sdk_path` 指向实际的 `MvImport` 目录
   （本机为 `E:\海康sadp\MVS\Development\Samples\Python\MvImport`，非默认路径）；
4. MVS 运行时 DLL 目录由 `camera_adapter.py` 自动补进搜索路径，无需手工配 PATH。

## 命令行参考

日常用不到命令行（双击 `测量.bat` 即可），标定和排错时才用。
所有命令在 `vision-roughness/` 目录下执行：

```bash
venv\Scripts\python.exe src\measure_ring.py                          # 相机现拍并测量
venv\Scripts\python.exe src\measure_ring.py --image <图片路径>        # 测已有照片（图放 data/captures/）
venv\Scripts\python.exe src\measure_ring.py --profile 型号1-6孔圆环 --ref-mm 88.60   # 标定该型号
venv\Scripts\python.exe src\measure_ring.py --image xxx.jpg --profile 型号2-4孔圆盘   # 按型号档案测
```

> **两个 `data\captures\` 别搞混**：标准验证照片在**仓库根**的 `data\captures\`，
> 从 `vision-roughness\` 下必须写 `..\data\captures\...`；
> 而 `vision-roughness\data\captures\` 放的是相机现拍的图（`measure_ring_latest.jpg` 等）。
> 路径写错会报「无法读取图片」。

| 参数 | 说明 |
|---|---|
| `--image <路径>` | 测已有照片；不指定则相机现拍 |
| `--ref-mm <mm>` | 零件**外径卡尺真值**，用于标定**机位**的 mm/px（写回 `models/rig.json`）|
| `--mm-per-px <系数>` | 临时指定换算系数，不写回档案 |

> 没有 `--profile` / `--spec-*` / `--tol` 了：**不命名就不判 OK/NG**，标称值请人工对照图纸。

## 换型号（型号档案）

不同型号的零件，外圈大小、孔径、孔数、**孔的分布**甚至"孔长什么样"都不一样，
所以每款零件在 `vision-roughness/models/part_profiles.json` 里存一份档案，用 `--profile` 选：

| 字段 | 含义 |
|---|---|
| `od_mm` | 外径**卡尺真值**（同时是本型号 mm/px 的标定依据）|
| `id_mm` / `has_center_hole` | 中心孔标称值；有没有中心孔 |
| `bolt_mm` / `bolt_count` | 螺栓孔标称值；孔数 |
| `bolt_angles_rel` | 各孔**相对**第 1 个孔的角度偏移（支持非等分布局）|
| `bolt_circle_ratio` | 孔心圆半径 ÷ 外圈半径 |
| `outer_fallback` | 可选：`bolt_anchor` = 外缘对比度太低时，用紧固件定圆心/期望半径再实测外圈（只有需要的型号才写）|
| `inner_rings` | 内圈清单 `[{name, mm}]`；`mm` 是标称值，按 `mm/od_mm` 圈定搜索带；测量取**两道边的中点**（见「检测管线」）|
| `locate` | **怎么定位孔**：`profile_angles`=按档案角度+相位搜索；`template_ngon`=暗斑模板匹配+n等分校验 |
| `boundary` | **量哪条边界**：`countersink_rim`=沉孔口阈值交叉；`dark_core`=暗芯中分界 |
| `mm_per_px` | 本型号的换算系数（**每个型号各一份**，尺度跟着机位走，不能跨型号复用）|
| `fingerprint_src` | 该型号识别指纹的参考图（参考图本身不入库，见下）|

**新做一款零件**：加一条档案（填尺寸 + 选 `locate`/`boundary`）→ 卡尺量外径 →
`--profile <型号名> --ref-mm <外径>` 标定一次（系数会**写回档案**）→ 之后测量时在下拉框或命令行
指定这个型号即可（**没有自动识别了，必须指定**）。

> **型号识别已删除（2026-10-23）**：以前那套"外圈环带极坐标指纹 + 孔型判据"两条识别路
> 已从代码里删干净，`models/fingerprints/` 也删了。现在**不指定型号就不猜**：只给像素、
> 标「未经验证」。所以 `--ref-mm` 和下拉框都要求你**明确选型号**——这本来就是回归门一直要求的
> 做法（`AGENTS.md` §3）。当年的设计留档在 `docs/设计决策记录.md` §5（**已废止**），
> 现场暴露的问题见 `docs/已知缺陷.md` 缺陷 2/5。

## 检测管线

核心在 `src/fit_ellipse_ring.py::detect()`：

1. **外圈** —— 72 条射线从外向内找最外侧强下降沿（抛物线插值到亚像素）+ 圆等价
   归一化距离滤离群 + 椭圆鲁棒拟合；再用粗结果做紧窗口精化。
   **定位是自适应的**：先按老先验（零件在画面正中 + 外圈半径 ≈ 短边的 44% + 下降沿）试，
   不行才换「候选圆心 × 径向直方图峰半径 × 两种极性」逐个打分，够可信才采用。
   所以零件偏出画面中心、换机位改变成像大小、或者零件比背景亮（上升沿）都能测到；
   老先验排在候选首位，所以原来能测的图读数逐位不变。
   **外缘对比度太低时**（深色件 + 暗背景），常规定位失败后若档案写了
   `outer_fallback: "bolt_anchor"`，会先用紧固件定圆心、按 `bolt_circle_ratio` 推期望半径，
   再在 ±7% 窄带里实测外径——外径仍是实测的，不是用孔圈比例反推。
2. **中心孔** —— 同一套射线法找暗→亮的上升沿；档案有 `id_mm/od_mm` 时用真值孔径比圈定
   窄带、带内取**最陡梯度**（型号1 内圈有三圈，只锁最内侧孔壁）。
3. **内圈** —— 档案 `inner_rings` 声明的每一圈：按 `mm/od_mm` 圈定窄带，分别找**进槽/出槽
   两条边**各拟一次椭圆，取两者的**中点**当直径（型号1 的 ~60/~78 各是一道环形槽；
   2026-10-22 实测 60.246 / 78.187mm，对真值 +0.41% / +0.24%）。找不到一正一负两条边
   就标「未测到」，不拿一条边硬充。
4. **螺栓孔** —— 由型号档案的 `locate`(怎么定位) + `boundary`(量哪条边界) 两个维度派发，
   **所有型号平级**；新增形态是加一个策略函数，不是加一条 if 分支。
   `template_ngon` 定位 + `countersink_rim` 边界（暗沉孔口那类）走下面三步：
   - 粗暗斑挖 250×250 模板 → 1/3 缩比模板匹配（`TM_CCOEFF_NORMED`）取峰；
   - **六孔等角共圆校验**：转到外圈椭圆归一化坐标系，用 RANSAC 思路选相位锚，
     生成 6 个 60° 等角槽位 —— 同时完成「滤假峰」和「补缺失孔」；
   - 逐孔：**螺丝头（暗斑内被包围的亮区）锚定孔心** → 沿射线枚举连续暗游程，
     取第一个**宽度 ≥12px** 的游程末端、按固定亮度阈值交叉定出**沉孔口**
     （跳过 5~15px 的螺丝槽纹/头影，防提前交叉）→ 极化残差**渐缩迭代**椭圆拟合
     （2.5×中位残差 → 1.0×中位，甩开与暗带粘连的远点；轴比 1.0~2.2 防塌陷）。
   - `core_hole`（装好紧固件的暗芯孔那类）另走一条：按档案的**相对角度 + 相位搜索**
     定位各孔（支持非等分布局，如 2×2 矩形），再从暗芯向外找**亮度中分界**、取
     **中位半径**当直径（刻意不拟合椭圆：暗芯一侧常连到阴影，一拟合就被拉长）。
     这条路**不需要中心孔**，所以实心盘也能测。

## 已知限制（重要，别误读读数）

> 完整清单（含证据、影响、修复方向、**停手与重新开工的条件**）在 **`docs/已知缺陷.md`**。
> 这里只留现场操作时最容易误读的几条。

- **螺栓孔测的是沉孔口口径**（含沉孔锥度），**不是螺纹孔径**。6 孔读数分散 ±7%
  （各孔 px 见 `AGENTS.md` §3 用例 1），含斜视透视（mm/px 随画面位置变化）+ 沉孔口
  阈值定义差异，**不能据此判定尺寸超差**。
- **中心孔（2026-10-21 已改）**：型号1 内圈有**三圈**——最内侧孔壁 **55.90**（要量的这条）、
  约 **60**、约 **78**（凸台内缘）。以前**锁错了圆**（近正对时读到 77.57mm，+38.8%），
  还会把螺栓孔搜索环带挖空。现在用档案的 `id_mm/od_mm`（型号1 = 0.633）圈定最内侧那圈的窄带、
  取最陡梯度：用例 1 从 61.44mm 收到 **57.86mm（+3.5%）**，新机位近正对短曝光实测孔径比
  0.630（−0.5%）。残差主要来自斜视投影，可作参考、**不得判超差**；没走档案时仍走旧逻辑，
  读数不可用。**注意**：当前自动曝光 105ms 会让亮环饱和、孔壁往内偏约 2%（0.618），另算一轮。
- **相机不垂直朝下时**：报告会自动打印透视提醒（角度由外圈椭圆长短轴比算出，不是假设值）。
  垂直拍摄后 mm/px 全视场恒定，标定一次通用。
- **这套读数达不到 5 丝（±0.05mm）**：单像素 ≈ 0.0327mm，5 丝 ≈ 1.5px；而沉孔
  缓坡边缘的实际定位误差 ±3~5px（≈±0.10~0.16mm）。要提精度得换垂直俯视 + 定向光，
  不是调参能救的。
- **毫米读数是"机位"的属性**：相机高度/距离/倾角一变，mm 就得对该型号重标（实测同一天内变过
  三次）。**怀疑读数的顺序应当是：比例尺（mm/px）变了？还是检出的是另一条边？**
  若是**比例不对**（两个尺寸的比值不对），那是"锁错了边"，调系数救不了。
  **2026-10-22 已按抬高后的固定高度重标型号1**（`mm_per_px = 0.043685`，指纹已重建）；
  **型号2 也已重标**（`0.044641`，126.0/2822.5px），但它的外圈是**紧固件锚定**的（外缘对比度低），
  重复性约 0.27%。换高度/光照/曝光策略任何一项变了都要重做。
- **自动曝光会压高光**：开机按均值标定后，若削顶像素（≥250）超过 `auto_sat_max`（默认 1%）
  会自动降曝光——亮金属过曝会把边缘往内推（实测孔壁比 0.630→0.618）。黑背景场景下均值到不了
  110，会打「现场偏暗」告警；只要外圈/中心孔稳定，这个告警可以忽略。若同时报「高光削顶」，
  说明动态范围太大，要补光/减弱直射反光，而不是继续压曝光。**曝光顶到上限（画面真暗）时**，
  螺栓孔模板会自动用到更低的 0.55 兜底档；再暗就分不出沉孔，需要补光。
- **型号 2 那类"装好紧固件"的孔，孔径读数单孔离散 ±15%**（**1.608**~2.144mm，标称 1.78，
  末位随档案里的系数精度走——现在是满精度，老文档写的 1.607 是系数舍入时的值），
  因为暗芯边界一侧常连到阴影。外径和"无中心孔"这两项是准的，**孔径只能当参考**。
- **同一个零件在台面上转个角度，检出的外径会变**（2026-10-08 实测）：转 47° 时外径
  2712.9 → 2780.3px（**+2.5%**，88.28mm 的件上就是 ±2.2mm）；个别转角下中心孔还会锁到别的
  结构上（47° 时 +25%）。原因是零件外缘是**一条有厚度的带**。**这与型号识别无关、现在就会
  影响使用**，属于另一轮（外缘/孔径定义在带内的稳定性）。
- **"外圈偏"和"螺孔少"不是因果，是同一个原因（倾角）**：外圈在螺栓孔之前算完，只吃灰度图
  和固定先验，**不看型号档案、不看中心孔、不看螺栓孔**（同一张图带档案/不带档案，外圈读数
  逐位相同）。现场判档位看报告里现成的两个数：**长短轴比**（1.000~1.002 = 近正对；
  ≥1.02 报告会打「透视提醒 斜视 N°」）和 **中心孔/外径**（≈0.88 = 锁到错圆、螺孔会整批消失；
  ≈0.70 = 环带没被挖空）。两档的实测数据与机制见 `docs/已知缺陷.md` 缺陷 1/6。
- **斜视时外径系统性偏低约 4%，其中一半不是检出误差**：报告的外径是 (长轴+短轴)/2，
  斜视必然把均值压小（φ=16.8° 时 −2.1%），另一半才是外缘带内的拟合漂移。所以斜视档的 mm
  **不能**和近正对档比；要比就比**长轴**（与倾斜无关）。连"同一零件躺平的角度变了"都要重标
  mm/px——回归用例 1（斜视 23°）与近正对两次标定差 5.7%（详见缺陷 3）。
- **不带档案时的"孔数"是猜的**：`infer_ngon_n` 在斜视档实测把 6 孔推成 **10**（报告列了 10 个
  槽位）。要按孔数解读，先确认走了 `--profile`（档案 `bolt_count`），否则 n 只是等分假设。
- **型号自动识别：型号2 能认（现场 7/7），型号1 认不出（现场 25 次 0 命中）** → 用窗口顶部的
  「型号」下拉框手工选。原因是判据的信息集中在**外缘带的明暗纹理**上（车削件换个光照/朝向，
  那一圈外观就变了）。门槛等参数只在 2 个零件上标定过，**拿到第三个零件必须复核**。
- **没有型号就不给毫米数**：识别失败、或传 `--profile none` 时，只输出像素并标「未经验证」——
  因为没有本型号的系数时，拿别的型号的系数印毫米数是错的。有档案但没标定过 `mm_per_px` 时同理。
- **「本型号没有中心孔」和「中心孔没测到」是两件事**：窗口分别显示**「无此孔」**（档案
  `has_center_hole=false`）和**「未测到」**（该有孔但没检出）。别把前者当成测量失败。
- **窗口的螺栓孔位是固定的 6 个**：型号 2 那种 4 孔零件会显示 4 个数 + 2 个「—」；
  孔数超过 6 时窗口会提示「本件检测到 N 个孔，界面只显示前 6 个」（不静默丢）。

## 环境与相机

- Python 3.11（`vision-roughness/venv/`）。**必须用 venv 的 python**，
  系统 Python 缺 cv2：`vision-roughness\venv\Scripts\python.exe`
- 相机：海康 **MV-CU120-10GM**（12MP 4024×3036，1/1.7" IMX226，黑白，卷帘，GigE，C 口）
  \+ 海康 DH25-10MP-23（25mm FA 定焦）；曝光锁 30000μs、增益 0（锁定亮度）
- 供电：DC 12V/1A（端子 橙=电源+，灰=电源−）；网线直连电脑，相机 IP 用 MVS 的
  IP 配置工具查看/修改（必须与电脑网卡同网段，IP 会随配置变化，别写死在文档里）
- MVS 装在 `E:\海康sadp\MVS\`（**SDK 路径非默认**，见 `src/config.py`）

### 踩过的坑

- GigE 包大小必须设 **1500 字节**（`GevSCPSPacketSize`）；网卡虚报巨型帧（8164）会丢包
- 12MP 实测 **约 7.7 fps**（单帧 0.13s，1500 字节包，2026-10-07 实机测得；
  早期记录的「一帧约 1 秒」已过时），取图超时设 3000ms
- **曝光按现场光自动标定一次再锁定**（`src/config.py` 的 `auto_exposure`，2026-10-07 加）：
  开机时二分试几帧、把画面平均亮度调到约 110 再固定，所以**启动后要等约 1~3 秒**才开始取景；
  上限 `auto_max_us=200000`（200ms），最暗时实时取景会掉到约 5 fps。
  背景：固定 30ms 在现场光不足时会把整帧打成全黑（实测均值 16/255，外圈检测全废，
  报「外圈拟合失败」），那比「亮度漂移」严重得多。要严格复现历史读数就把
  `auto_exposure` 改回 `False`（见 `camera_adapter.py` 类注释里的历史说明）
- `测量.bat` 内容必须是 **ASCII + CRLF**；存成 UTF-8 或 LF 会导致 cmd 乱码报错

### 排错速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 报错码 `0x80000203` | 相机被 MVS 客户端占用 | 关掉 MVS 软件，再点「再测一次」 |
| 「没找到相机」 | 网线 / 供电 / 网段 | 查网线与相机指示灯，确认网卡与相机同网段 |
| 「能看见但取不到图」 | 占用 / 网线松动 / IP 冲突 | 关 MVS；查是否有两台设备同 IP |
| 取图超时 `0x80000007` | 同上 | 跑 `venv\Scripts\python.exe temp\hik_debug.py` 逐环节定位 |
| 「外圈拟合失败」且画面发黑 | 现场光不足 / 曝光太低 | 确认没被 MVS 占用后重开程序（会重新自动标定曝光）；仍失败就补光 |
| 报「外圈超出画面：检出的是内孔…」 | 零件太大或偏出画幅，外缘被切掉 | 把零件移到画面中心（或把相机抬高/后拉），让整圈外缘完整可见再测 |
| 「未识别到型号…请在「型号」里选 / 用 --profile」 | 这次没指定型号（自动识别已于 2026-10-23 删除） | 在窗口顶部「型号」下拉框里选一个（没有对应型号就选「无档案试测」，此时**只给像素**），或命令行加 `--profile <型号名>` 重测 |
| 螺栓孔全部测不到 / 只测到一半 | ① 没走档案时中心孔仍会锁到 0.879 的错圆；② 斜视时一侧沉孔被光打亮；③ 单个孔的沉孔口边界量不出来 | 看报告：**中心孔/外径 ≈0.88** = 没走档案（请先选型号）；**长短轴比 ≥1.02** = 还没正对。沉孔太亮（缺陷 7）与环面暗槽吞掉沉孔（缺陷 9）都已修；仍全 0 就查光照/对焦。详见 `docs/已知缺陷.md` 缺陷 1/6/7/9 |
| 「没找到海康 SDK」 | MVS 未装完整或路径不符 | 重装 MVS（勾选 Python SDK），或改 `config.py` 的 `sdk_path` |
| `No module named cv2` | 用了系统 Python | 改用 `venv\Scripts\python.exe` |
| 窗口里数字都是「—」 | 检测失败 | 看窗口红底提示；检查对焦、光照、零件是否在画面中心 |

## 换相机 / 换支架 / 重新标定

**任何改变"相机与零件相对位置/角度"的操作都算换机位**——换相机、换支架、调高度、挪工位、
把零件垫高，都要把下面四步走完。只换支架、不换相机时第 1 步可跳过。

1. 改 `src/config.py` 的 `CAMERA_TYPE` / `CAMERA_KWARGS`（业务代码零改动）；
2. 卡尺量出零件外径真值，重新标定**该型号**的 mm/px 换算系数（系数只存在型号档案里，
   每个型号各一份）：

   ```bash
   venv\Scripts\python.exe src\measure_ring.py --profile <型号名> --ref-mm <外径真值mm>
   ```

3. 换算系数跟着「相机 + 镜头 + 拍摄距离 + **倾角**」走，**任一变化都必须对该型号重新标定**。
   换支架后先验"是不是真的正对"：拿新拍的图看报告里的外圈椭圆，**长短轴比 ≈1.000~1.005**
   才算正；≥1.02 会打「透视提醒」，说明还斜着（此时均值直径会系统性偏小）。

## 诊断工具

改检测参数时按这个顺序用，均为 `venv\Scripts\python.exe src\<脚本>.py <图片路径>`：

| 脚本 | 用途 |
|---|---|
| `explore_ring.py` | 摸清外圈/中心孔/螺栓孔/背景的灰度分布，为阈值定参 |
| `profile_ring.py` | 径向距离直方图找半径峰，定位圆心与外圈直径 |
| `ray_ring.py` | 打印指定中心 8 个方向的边缘列表（距离/梯度/灰值） |
| `edge_ring.py` | Canny+轮廓 与 缩图 HoughCircles 的路线对比 |
